# Sprint_6
Локаторы
- locators/main_page_locators.py — локаторы для главной страницы (кнопки, логотипы, вопросы FAQ).
- locators/order_page_locators.py — локаторы для страницы оформления заказа (поля формы, календарь, выпадающие списки, кнопки).

Данные для тестов:
- data/faq_tests.py — тестовые данные для проверки вопросов и ответов блока FAQ.
- data/order_data.py — тестовые данные для оформления заказа (имя, фамилия, адрес, телефон, комментарий).
- data/urls.py — хранение основных ссылок для тестов.

Pages:
- pages/base_page - базовый класс page
- pages/main_page.py — Page Object для главной страницы: методы для работы с кнопками, логотипами и блоком FAQ.
- pages/order_page.py — Page Object для страницы оформления заказа: методы для заполнения полей формы, выбора даты, периода аренды, цвета и подтверждения заказа.

Тесты:
- tests/test_main_page.py — тесты для главной страницы:
  - test_faq_answers — проверяет, что при клике на вопросы FAQ отображаются правильные ответы.
  - test_order_button_header_opens_form — проверяет переход к форме заказа при клике по кнопке "Заказать" в хедере.
  - test_order_button_page_opens_form — проверяет переход к форме заказа при клике по кнопке "Заказать" на странице.
  - test_logo_scooter_redirect — проверяет переход на главную страницу через клик по логотипу скутера.
  - test_logo_yandex_redirect — проверяет переход на сайт Яндекс.Дзен при клике по логотипу Яндекса.
- tests/test_order.py — тесты для оформления заказа:
  - test_make_order_from_page — оформление заказа через кнопку "Заказать" на странице.
  - test_make_order_from_header — оформление заказа через кнопку "Заказать" в хедере.
  В обоих случаях проверяется заполнение формы, подтверждение заказа и отображение окна с сообщением "Заказ оформлен".

helpers/order_helpers.py - вспомогательные модуль для test_order.py
Описание Page Object:
- HomePageSamokat  — методы для работы с куками, кликами по кнопкам и логотипам, а также функционал для блока FAQ.
- OrderFormPage — методы для работы с формой заказа: заполнение данных, выбор даты и периода аренды, выбор цвета самоката, добавление комментария, подтверждение и проверка успешного оформления заказа.
